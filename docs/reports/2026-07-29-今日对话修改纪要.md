## 二、HJ诊室门边屏终端

### 2.1 「暂无医生坐诊」在安卓上偏到左上角

- **问题：** `.duty-mask` 使用 `inset: 0`，部分安卓 WebView 不支持，遮罩塌成内容大小并落在左上角。
- **修复：** 改为显式 `top/right/bottom/left: 0`。
- **文件：** `DoctorSingle.vue`、`DoctorDual.vue`、`DoctorPlaceholder.vue`、`ScreenFrame.vue`。

### 2.2 设备在线但后台显示「未连接」

- **问题：** 后台用 `doc_screen.last_seen_at`（约 5 分钟窗口）判断在线；门边屏业务页只轮询 `GetDisplay`，此前不刷新心跳。
- **修复：** 在 `ClinicScreenServiceImpl.buildDisplay` 查到设备后调用 `touchLastSeen`（与签到终端一致）。
- **生效：** 重启 `pdjh-server`，门边屏再拉一次展示数据后刷新后台。

## 四、HJ音响终端与叫号播报

### 4.1 部署说明（未改代码，结论）

- 设备主数据在后台「独立音响管理」维护；本机只填后端地址与设备编号。
- **自包含发布**（`--self-contained true`）时，现场**不必**再装 `windowsdesktop-runtime`。

### 4.2 播报动词错误（「就诊」被播成「检查」）

- **原因：** 用错 `department.type`（组织树层级），末级科室几乎都播成「检查」。
- **修复：** 按 `businessType` 生成动词：门诊→就诊，LAB/EXAM→检查，PHARMACY→取药。
- **位置：** `DoctorCallServiceImpl.docCallMsg`。

### 4.3 中文 TTS（只播 “five one”）

- **原因：** 默认英文语音（如 Zira），汉字被跳过。
- **修复：** `TtsQueue` 优先 `zh-CN` / 中文语音，并用中文 `PromptBuilder`。

### 4.4 音量与音色

- 设置窗新增：音色下拉、音量滑条（0–100），写入本地 `config.json`。
- 下拉框深色主题模板；选中项绑定 `SelectedItem.Display` 以正确显示文字。

### 4.5 程序图标

- 新增 `Assets/app.ico`，应用与托盘统一使用。

### 4.6 播报文案对齐大屏「语音播报」模板

- 独立音响与大厅叫号共用大屏 `CallContent`：`{0}` 号序、`{1}` 姓名、`{2}` 诊室。
- **模板无单独缓存**；每次叫号读库。改模板不生效时先核对：后端是否已加载新代码、改的是否为实际关联大屏、音响是否绑对屏。

### 4.7 多屏同诊室时模板选错

- **现象：** 改了候诊大屏模板仍播诊室屏格式。
- **原因：** 音响未绑 `screen_id` 走旧诊室绑定；同诊室多屏时优先命中了 CLINIC 模板。
- **修复：** 优先使用候诊大屏（SCREEN）的语音播报模板；现场需确认音响绑定正确。

## 五、播报通道与绑定模型（重要业务调整）

### 5.1 绑定方向调整

| 之前 | 现在 |
|------|------|
| 音响 → 绑一块大屏（或诊室/诊区） | **大屏 → 勾选多台音响**（多对多）；一台音响可被多块大屏共用 |

- 存储：`voice_scope_mapping(scopeType=SCREEN)`；旧 `voice_device.screen_id` 可读兼容。
- 独立音响管理侧重台账；**屏幕管理 → 候诊大屏** 负责「绑定音响」与播报通道。

### 5.2 播报通道

大屏可配置：`独立音响` / `大屏播报` / `同时`。

- 音响故障：将该屏通道改为「大屏播报」（主机需有音箱）。
- 通道为「独立音响」但无可用设备时，**自动降级**为大屏浏览器 TTS。
- 候诊大屏 `default` / `default-mul` / `default-mul-col` + mixin 恢复 TTS。

### 5.3 屏幕管理 UI

- 「播报通道 + 绑定音响」同一行；通道用按钮组；多选折叠标签，避免换行撑高。

### 5.4 呼叫次数 / 语速 / 滚动间隔贯通

| 配置项 | 行为 |
|--------|------|
| 呼叫次数 | 广播与音响推送带 `callNum`；大屏 TTS、音响均按 1–5 次重复 |
| 语速（-10～10） | 推送带 `rate`；大屏映射 `utterance.rate`；音响写 `SpeechSynthesizer.Rate` |
| 滚动间隔 | `/default-mul`、`/default-mul-col` 候诊列表滚动时长使用该配置（秒，至少 3） |

**生效：** 重启后端 + 刷新/重启候诊大屏 + 重新部署音响终端。

## 六、HJ管理后台

### 6.1 新增/修改菜单弹窗布局

- 统一双列网格（`span=12`，`gutter=20`），弹窗宽 640px，控件拉满列宽。
- 字段顺序：名称|上级 → 路径|重定向 → 图标|是否显示 → 是否缓存。
- **文件：** `maintenanceMenu/index.vue` 等。

### 6.2 门诊主任工作台去写死数据

「医生出诊实时看板」等改为正式接口查询：

| 区块 | 数据来源（示意） |
|------|------------------|
| 医生出诊看板 | `/dashboard/outpatient/doctor-duty-board` |
| 科室过号率 | `/dashboard/outpatient/skip-rate-ranking` |
| 号源配额 | `/dashboard/outpatient/quota-overview`（排班 `max_quota`） |
| KPI / 过号数 | `getOverviewMetrics` 增加 `skipCount` |
| 恢复出诊 | `/Doctor/ResumeDuty` |

- 看板展示：当前在诊或今日临时停诊的门诊医生；号源依赖排班 `max_quota`。
- **主文件：** `directorDesk/outpatientDesk/index.vue` + `DashboardController` 等。

### 6.3 队列明细患者状态表述

状态码与叫号器口径对齐：

| 状态码 | 现显示 |
|--------|--------|
| 0 | 候诊待呼 |
| 1 | 就诊中 |
| 4（及旧码 2） | 就诊完成 |
| 6（及旧码 3） | 已过号 |
| 9 | 已作废 |

- 编辑下拉写入 `0/1/4/6/9`；批量清理筛选同步。
- 门诊超时过号写入 `state=6`（此前误写为 4）。
- **根因：** 完成就诊为 `state=4`，旧规则把非 0/1/2 都标成「已过号」。
