# 显示屏终端分层说明

> **文档位置：** `docs/architecture/` · 与 [实施与部署方案](../deployment/实施与部署方案.md)、[android-shell-spec](../android/android-shell-spec.md) 同步维护。

## 1. 分层原则

| 层级 | 策略 | 说明 |
|------|------|------|
| **配置层** | 统一 | `doc_screen` 表 + 后台「屏幕管理」；`terminalType` 区分 SCREEN / CLINIC |
| **渲染层** | 分离 | `HJ候诊区大屏`（Vue3，`/screen/`）与 `HJ诊室门边屏终端`（Vue3，`/clinic/`） |
| **接入层** | Shell 分流 | SCREEN 壳 → `/screen/`；CLINIC 壳 → `/clinic/` |

## 2. 终端职责

### 候诊区大屏 (SCREEN)

- 项目：`HJ候诊区大屏`
- 场景：候诊区横屏、多诊室汇总叫号
- 路由：`/pdjh1`～`/pdjh8`、`/GlobalHub`、`/directorDashboard`
- 配置：`templateRoute` + `SCREEN_CFG_{id}`（后台「候诊区大屏显示配置」）

### 诊室门边屏 (CLINIC)

- 项目：`HJ诊室门边屏终端`
- 场景：诊室门口 9:16 竖屏，一室一屏
- 接口：`ClinicScreen/GetDisplay`
- 配置：后台绑定 1 个物理诊室 + `CLINIC_CFG_{id}`（后台「门边屏显示配置」）；**不使用** `templateRoute`

### Legacy 模板

- `pdjh2`、`pdjh9` 为历史门边屏方案，路由仍保留兼容；新现场请部署 `HJ诊室门边屏终端`。

## 3. Resolve 语义

- `Terminal/Resolve?terminalType=SCREEN`：返回 `templateRoute`（默认 `/pdjh1`）
- `Terminal/Resolve?terminalType=CLINIC`：`templateRoute` 为空；由 CLINIC 壳固定进入 `/clinic/`
- `Screens/GetDeviceRoute`：已废弃，仅 SCREEN 壳；CLINIC 设备返回 400

## 5. 配置键对照

| 终端 | 后台菜单 | sys_config 键 |
|------|----------|---------------|
| SCREEN | 候诊区大屏配置 | `SCREEN_CFG_{screenId}` |
| CLINIC | 门边屏显示配置 | `CLINIC_CFG_{screenId}` |

## 6. 误装防护

- SCREEN 壳解析到 CLINIC 设备 → 候诊大屏 `/wrong-terminal`
- CLINIC 壳解析到 SCREEN 设备 → 门边屏绑定页提示
