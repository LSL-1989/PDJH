# 欢匠 PDJH - 移动体检导引与自调系统 (Exam H5)

本项目是为高端体检场景中（含有 B超、CT、内外科等多科室流转的综合业务）专门定制研发的 C 端微服务。

## 核心定位

颠覆传统的“纸质导检单”，建立用户掌上的**动态体检状态机**。

## 业务能力

1. **全景代办视图**：展示患者体检清单中的 `PENDING` (待检)、`WAITING` (队列中) 和 `FINISHED` (已结) 以及对应的等待区拥挤程度（排队位数）。
2. **手机自助改签与路由 (Self-Adjustment)**：允许患者动态向引擎发起算路请求，抛弃当前派发的拥挤长龙，重新选择其它空闲医技。
3. **闭环融合**：所有动作与后台的体检图谱依赖挂钩，确保符合医学上的检验先决条件（如：必须先抽血才能做彩超）。

## 运行与编译
现代化的前端体验构造基础：
```bash
npm install
npm run dev
```
