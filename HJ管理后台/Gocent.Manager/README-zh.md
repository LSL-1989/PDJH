# 欢匠 PDJH - HJ管理后台

**HJ管理后台**（目录 `HJ管理后台/Gocent.Manager`）是整个“欢匠智慧医院全场景排队叫号系统”的超级管理员管控中心，衍生自 `vue-admin-template` 面板。

## 职能定位

为医院信息化管理团队 (IT、院办、医务处) 提供全局配置的统筹入口。

## 核心业务板块

1. **统一数据字典**
   - 科室信息管理、医生档案管理、VIP/老弱病残优先策略预设。
   
2. **医技中心工作流定义 (Phase 11 新增)**
   - 对于涵盖“心电图、核磁共振、四维彩超、检验科抽血”的复杂大体检中心，支持定义树状结构的医学前置依赖图。
   - 实现“先抽血，再做 B 超”的科学排队锁控制。
   
3. **特权账号发行**
   - 包含签到器二维码发放与特权加塞权限配给控制。

## 开发与编译
```bash
# 推荐使用 npm 镜像安装
npm install --registry=https://registry.npmmirror.com

# 启动本地开发服务端口 9528
npm run dev
```
